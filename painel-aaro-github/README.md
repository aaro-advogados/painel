# Painel AARO

Painel de performance Meta Ads da AARO Advogados Associados.
Atualiza sozinho de hora em hora, das 8h às 17h (Brasília), de segunda a sexta, exceto feriados nacionais.

- Atualizar agora: Actions → Atualizar painel → Run workflow.
- O token do Meta fica em Settings → Secrets → `META_TOKEN`.
